# 개발 기록

이 디렉터리는 구현 과정에서 확인한 기술 문제, 보안 검증 결과, 법률 검토 과제와 후속 리서치 아이디어를 관리한다. 제품 요구사항과 확정된 컨트랙트 설계는 루트 및 `contracts/README.md`에서 관리하고, 여기에는 판단 근거와 아직 해결되지 않은 질문을 남긴다.

## 기록 원칙

- 발견 날짜, 영향을 받는 범위와 현재 상태를 함께 기록한다.
- 코드로 해결한 문제는 관련 테스트 이름과 커밋을 나중에 추적할 수 있게 남긴다.
- 법률 쟁점은 기술 구현으로 해결되는 문제와 외부 계약·인가·운영으로 해결할 문제를 구분한다.
- 가설과 확인된 사실을 구분하고, 외부 자료를 사용한 경우 원문 링크와 기준일을 남긴다.
- 해결되지 않은 위험을 삭제하지 않고 상태를 갱신한다.
